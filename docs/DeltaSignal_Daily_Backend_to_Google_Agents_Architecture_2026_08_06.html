Daily does not mean “new filing every day.”

The scheduler refreshes snapshots, deltas, materializations, quality, and history. The answer must retain both filing dates and computation dates.

Point-in-time is a separate contract.

Historical analysis filters facts by filed date. Later amendments cannot silently rewrite what an agent could have known earlier.

Levels are independent.

Level 1 can be available while Levels 2–4 are partial or missing. The agent reports each state rather than manufacturing one aggregate certainty.

Google Cloud does not own the evidence.

Cloud Run coordinates bounded tools and Gemini explains them. DeltaSignal remains the evidence and provenance authority.
