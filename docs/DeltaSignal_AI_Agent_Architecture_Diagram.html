Audited architecture diagram · Track 3

One TripCode becomes a reusable agent packet.

DeltaSignal converts published HUT research into agent-executable diligence. A Cloud Run agent exposes discoverable A2A skills, accepts TripCode or issuer intent, calls ATLAS-7 evidence surfaces, uses River memory for continuity, and returns a bounded research packet with caveats and usage visibility.

01 Discover

Agents inspect the public Agent Card, live demo, and route contracts before execution. This avoids hidden endpoint knowledge and supports marketplace-style discovery.

02 Invoke

The HUT proof starts from TF-SUB-9DA70A7F98. The request becomes a bounded TripCode/River workflow instead of a generic market chat.

03 Verify

The returned packet separates article memory, evidence identity, missing data, inference, session state, usage telemetry, and non-advice boundaries.
