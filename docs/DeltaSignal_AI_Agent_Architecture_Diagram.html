Architecture diagram · Track 3

One TripCode becomes a reusable agent packet.

DeltaSignal converts published research into agent-executable diligence. A Cloud Run agent accepts a ticker, issuer request, or TripCode; calls ATLAS-7 and River memory; synthesizes through Gemini; and returns a bounded A2A-ready research packet.

Public Diagram URL Direct Image URL
Discover

External clients inspect the Agent Card, OpenAPI/MCP surface, workflow metadata, and protected access requirements before execution.

Invoke

A user or agent submits a bounded HUT TripCode or issuer-diligence request to the Cloud Run service.

Verify

The returned packet separates article memory, evidence identity, missing data, inference, usage telemetry, and non-advice boundaries.
