How the Google agents call DeltaSignal MCP

The browser never receives an MCP credential. A Google Cloud coordinator creates a bounded plan, server-side specialists call named read-only tools, and the returned evidence envelopes remain attached when Gemini explains the result.

What the specialist preserves
  • Issuer identity, CIK, filing form, period, and accession when returned.
  • Reported financial values with their units and source dates.
  • Quality flags, evidence hashes, caveats, route provenance, and access status.
  • An explicit unresolved state when Apple Intelligence attribution or another requested field is not disclosed.

The four specialist agents

Each specialist has one bounded MCP tool. The coordinator preserves the raw response and stable call order before any Gemini synthesis occurs.

1

Filing facts

deltasignal_company_fundamentals

Revenue, income, cash flow, balance-sheet values, form, period, CIK, accession, source date, and provenance.

2

CompanyFacts inventory

deltasignal_atlas7_companyfacts_history

Materialized issuer inventory, tag coverage, taxonomies, quality, evidence hashes, and source pointers.

3

Point-in-time history

deltasignal_atlas7_point_in_time_history

What could have been known by a cutoff date, including filed-date filtering and look-ahead safety flags.

4

Level applicability

deltasignal_atlas7_four_level_applicability

Independent readiness for issuer truth, market behavior, basket pressure, and depth/reference dislocation.

What happens when a client asks a question

1 · IntentAAPL question plus optional as-of date.
2 · PlanCoordinator selects the four fixed evidence lanes.
3 · RetrieveSpecialists call read-only MCP tools in parallel.
4 · ClassifyFact, calculation, interpretation, scenario, unresolved, access.
5 · ReviewMissingness and contradictions are checked.
6 · ExplainGemini produces a bounded brief with raw evidence attached.

Deploy the client to Cloud Run

Fixture deployment

  • Build from the repository root with the supplied Dockerfile.
  • Set AAPL_DEMO_MODE=fixture.
  • No DeltaSignal credential. No Gemini call. No payment capability.
  • Use this for public evaluation and repeatable demonstrations.

Live deployment

  • Set AAPL_DEMO_MODE=live and optionally AAPL_DEMO_SYNTHESIS=gemini.
  • Mount the MCP credential from Secret Manager into the private Cloud Run service.
  • Keep the browser and public repository credential-free.
  • Use service-to-service IAM; log status and tool names, not secrets or full paid payloads.
Build and deploy · adapt PROJECT_ID and REGION
gcloud builds submit \
  --config client-demo/google-cloud-aapl/cloudbuild.yaml \
  --substitutions _IMAGE=REGION-docker.pkg.dev/PROJECT_ID/deltasignal/aapl-client-demo:latest \
  .

gcloud run deploy deltasignal-aapl-client-demo \
  --image REGION-docker.pkg.dev/PROJECT_ID/deltasignal/aapl-client-demo:latest \
  --region REGION \
  --set-env-vars AAPL_DEMO_MODE=fixture,AAPL_DEMO_SYNTHESIS=deterministic

The trust contract

Evidence can establish

What a filing reports, what was available by a date, which data surfaces exist, and which provenance accompanies a result.

ATLAS-7 can interpret

How supported evidence fits a consistent structural framework—while keeping the interpretation distinct from reported facts.

The agent cannot invent

Apple Intelligence revenue attribution, missing market layers, direct equity depth, unsupported calculations, or confidence not returned by evidence.
