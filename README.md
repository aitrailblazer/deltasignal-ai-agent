# DeltaSignal AI Agent

Competition workspace for the Google for Startups AI Agents Challenge.

## Google Cloud Project

This folder is associated with:

```text
startup-ai-deltasignal
```

For local shells, load the project environment with:

```bash
source .envrc
```

If `direnv` is installed, run:

```bash
direnv allow
```

Expected local Google Cloud context:

```bash
gcloud config set account constantine@aitrailblazer.com
gcloud config set project startup-ai-deltasignal
gcloud auth application-default set-quota-project startup-ai-deltasignal
```
